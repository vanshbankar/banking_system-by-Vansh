# banking_system-by-Vansh
A Python-based banking system simulation demonstrating OOP concepts like classes, objects, encapsulation, and basic account operations.


🏦 Python Banking System

A simple banking system simulation built with Python to practice Object-Oriented Programming (OOP) and basic programming concepts.

📌 About the Project

This project simulates basic banking operations using a Python class.

Each bank account is represented as an object, and users can perform basic operations such as:

- Creating a bank account
- Checking account balance
- Adding money to an account
- Withdrawing money from an account
- Handling insufficient balance
- Validating transaction amounts

This is a learning project, not a real banking application.

▶️ How to Run

Make sure Python 3 is installed on your computer.

Clone the repository:

git clone https://github.com/vanshbankar/banking_system-by-Vansh.git

Move into the project folder:

cd banking_system-by-vansh

Run the program:

python banking_system.py
